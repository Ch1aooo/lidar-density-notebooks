Chapter outline
What works here? Browser explorers run locally in your browser: no Julia installation or running author computer is needed. This includes the walk viewer's fixed-bandwidth XY/XYZ MSP calculation and the separation page's reproducible synthetic scene. Notebook chapters are published calculation snapshots. Controls that generate a new notebook input or change the Julia accumulation model require the local Julia version. Clusters, point groups and peaks are candidates, not verified person identities.
