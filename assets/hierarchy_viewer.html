Definitions, formulas and units

ρ(x) = Σ exp(−‖x−xᵢ‖²/(2σ²))/(2πσ²), in returns/m². Every kernel integrates to 1 over the full plane. We integrate the linear density, never the dB display.

R is the connected region strictly above its own merge saddle s; h is its peak height. N̂ = ∫R ρ dA; X = ∫R (ρ−s) dA; N is the direct original-point count in R using nearest grid nodes. Smoothed counts may be fractional. Boundary smoothing, finite-window tails and grid quadrature cause discrepancies; N̂−N is not person-detection accuracy. Nested branch regions overlap and must not be summed.

The essential root has no finite merge saddle, so its branch metrics remain undefined. Parent records the elder representative peak, not an anatomical parent. A retained mode is a candidate, not a verified person.

Definitions and limitations

All local peaks remain in the tree under 8-neighbour connectivity. Pruning changes the retained-candidate labels, not the point cloud or the density landscape. The root is retained by convention.

The two-person arm preset contains two body supports (120 and 110 returns) and a weak 24-return protrusion attached conceptually to the first person. Source composition is evaluation-only; no person labels enter the hierarchy. Small σ may split anatomy; large σ may merge people. Look for a useful interval, not a guaranteed count.

Density units are returns/m²; integrated density is a smoothed return count, not body volume. dB changes colour or axis display only. Peak IDs are local to each σ, not temporal identities. E compares counts, without matching branches between bandwidths.
