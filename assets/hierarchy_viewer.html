Definitions, formulas and units

ρ(x) = Σ exp(−‖x−xᵢ‖²/(2σ²))/(2πσ²), in returns/m². Every kernel integrates to 1 over the full plane. We integrate the linear density, never the dB display.

R is the connected region strictly above its own merge saddle s; h is its peak height. N̂ = ∫R ρ dA; X = ∫R (ρ−s) dA; N is the direct original-point count in R using nearest grid nodes. Smoothed counts may be fractional. Boundary smoothing, finite-window tails and grid quadrature cause discrepancies; N̂−N is not person-detection accuracy. Nested branch regions overlap and must not be summed.

The essential root has no finite merge saddle, so its branch metrics remain undefined. Parent records the elder representative peak, not an anatomical parent. A retained mode is a candidate, not a verified person.

E · Bandwidth sensitivity at fixed input

Dots are computed bandwidths; connecting lines are guides. Target count is evaluation-only and never selects parameters. Count agreement does not verify correct locations or identities. Once smoothing removes a peak, pruning cannot recover it.

Definitions and limitations

All local peaks remain in the tree under 8-neighbour connectivity. Pruning changes candidate labels, not points or density. The root is retained by convention.

Mass share q = N̂branch / Σ N̂siblings is measured on disjoint regions strictly above the SAME merge saddle. It compares return support, not peak height, physical weight or body volume. Siblings may already contain multiple peaks; share is local to each event and is not directly comparable to a fraction of a whole person.

Small and large attached contributions have 24 and 60 returns, respectively, beside identical 120/110-return body supports. A weak independent target tests the opposite error: rejecting a person with few returns. Size alone cannot establish semantic ownership; a large carried object and a small person can be ambiguous in one static frame.

Guarded defaults (share 20%, height 5%, excess 2%) are exploratory. Original 20%/10% shape thresholds remain a fixed baseline. dB is display-only. IDs are local to each σ; E does not match branches across bandwidths.

Validation: fixed policies on three additional seeds

Same eight geometries, seeds 28–30, fourteen σ samples each. Exact target-count matches out of 42 scene/σ evaluations: original → guarded mass-share rule: two targets 29 → 37; three targets 20 → 27; small attachment 34 → 39; large attachment 31 → 28; 4:1 weak target 11 → 1. These are correlated bandwidth evaluations of only three clouds per scene, not independent trials or real-person accuracy. No parameters were retuned after these results. Size helps some scenes and harms unequal-support targets.
